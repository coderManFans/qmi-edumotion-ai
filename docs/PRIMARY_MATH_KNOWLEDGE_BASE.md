# 中国小学数学题型与公式知识库

> 版本：v1.0（工程整理版）  
> 课程依据：教育部《义务教育数学课程标准（2022年版）》小学部分。  
> 说明：不同教材版本的年级编排可能不同，年级仅作大致参考；具体教学应以学校教材和学生进度为准。

## 1. 设计原则

本知识库不是“关键词命中就套公式”的答案生成器。解题必须依次完成：

1. **读题**：保留题目原文，识别对象、条件、问题。
2. **提取量**：每个数值都标注量名、单位、对象和角色。
3. **建关系**：用文字、表格、线段图或图形说明数量关系。
4. **选公式**：解释公式为什么适用。
5. **变形**：未知量不在公式左侧时，展示等价变形。
6. **计算**：列出代入过程，统一单位。
7. **作答**：带正确单位回答题目。
8. **验证**：代回公式、逆运算或根据题意检查合理性。

任一关键环节缺信息时，标记为“尚未验证”，说明需要补充的条件；不能编造答案。

## 2. 小学常见题型地图

| 领域 | 常见题型/知识点 | 主要关系或公式 | 典型反向求解 |
|---|---|---|---|
| 数与运算 | 合并、增加、减少 | 总量=部分1+部分2；剩余=原有-用去 | 已知总量和一部分求另一部分 |
| 数与运算 | 倍数、平均分、包含除 | 总数=每份数×份数；每份数=总数÷份数 | 已知总数与每份数求份数 |
| 数与运算 | 单价、数量、总价 | 总价=单价×数量 | 已知总价和单价求数量 |
| 数与运算 | 平均数 | 平均数=总和÷份数 | 总和=平均数×份数 |
| 数与运算 | 分数应用题 | 部分量=单位“1”×对应分率 | 单位“1”=部分量÷对应分率 |
| 数与运算 | 百分数、折扣、增长率 | 部分量=整体量×百分率；现价=原价×折扣率 | 整体量=部分量÷百分率 |
| 数与运算 | 比与按比分配 | 每份量=总量÷份数和 | 各部分=每份量×对应份数 |
| 数与运算 | 行程问题 | 路程=速度×时间 | 速度=路程÷时间；时间=路程÷速度 |
| 图形与几何 | 正方形 | 周长=边长×4；面积=边长×边长 | 边长=周长÷4 |
| 图形与几何 | 长方形 | 周长=(长+宽)×2；面积=长×宽 | 长=周长÷2-宽 |
| 图形与几何 | 三角形 | 面积=底×高÷2 | 底或高=面积×2÷另一边 |
| 图形与几何 | 平行四边形 | 面积=底×高 | 底或高=面积÷另一边 |
| 图形与几何 | 梯形 | 面积=(上底+下底)×高÷2 | 高=面积×2÷(上底+下底) |
| 图形与几何 | 圆 | 周长=π×直径；面积=π×半径² | 直径=周长÷π |
| 图形与几何 | 长方体/正方体 | 长方体体积=长×宽×高；正方体体积=棱长³ | 已知体积和两个维度求第三个 |
| 测量 | 单位换算 | 长度、面积、质量、时间、容积的进率 | 面积进率平方、体积进率立方 |
| 统计与概率 | 统计表、条形图、折线图、平均数、可能性 | 按数据与图表信息分析 | 不得推断图表未提供的数据 |

机器可读取的完整元数据见 `backend/app/knowledge/elementary_math.json`。

## 3. 公式讲解与标准例题

### 3.1 正方形周长反求边长

题目：一个正方形周长是16厘米，求边长是多少？

- 已知：周长 (C=16\text{厘米})
- 所求：边长 (a)
- 知识点：正方形四条边长度相等；周长是四条边长度之和。
- 公式：(C=4a)
- 变形：(a=C\div4)
- 代入：(a=16\div4=4\text{厘米})
- 验证：(4\times4=16\text{厘米})，与已知周长相符。
- 答：边长是4厘米。

动画应呈现四条等长边依次相加，再将周长平均分成4份；不能只展示“16÷4=4”。

### 3.2 长方形周长反求宽

题目：一个长方形周长是30厘米，长是9厘米，宽是多少？

- 已知：(C=30\text{厘米}, a=9\text{厘米})
- 公式：(C=2(a+b))
- 变形：(b=C\div2-a)
- 代入：(b=30\div2-9=15-9=6\text{厘米})
- 验证：((9+6)\times2=30\text{厘米})
- 答：宽是6厘米。

### 3.3 三角形面积

题目：三角形底是8厘米，高是5厘米，面积是多少？

- 公式：(S=底\times高\div2)
- 代入：(8\times5\div2=20\text{平方厘米})
- 理由：同底等高的平行四边形面积是三角形的2倍。
- 检查：面积单位必须是平方厘米，不是厘米。

### 3.4 单价、数量、总价

题目：每支笔6元，买4支，一共多少元？

- 关系：总价=单价×数量
- 代入：(6\times4=24\text{元})
- 反向题：总价24元，每支6元，数量=(24\div6=4\text{支})。

### 3.5 行程问题

题目：汽车每小时行驶60千米，行驶3小时，路程是多少？

- 关系：路程=速度×时间
- 代入：(60\times3=180\text{千米})
- 检查：速度单位是千米/小时，时间单位是小时，结果单位是千米。

### 3.6 百分数/折扣

题目：一件商品原价200元，打八折，现价多少元？

- 八折表示原价的80%。
- 公式：现价=原价×折扣率
- 代入：(200\times80\%=160\text{元})
- 检查：打折后价格应低于原价。

## 4. 必须显式处理的易错点

- **单位错误**：长度、面积、体积量纲不同；不能把厘米直接加到平方厘米。
- **量的角色颠倒**：单价×数量与总价÷单价要根据所求量选择。
- **单位“1”不明确**：分数、百分数应用题先确定整体是谁。
- **公式逆用**：已知周长求边长时必须展示公式变形。
- **图形中的高**：三角形和平行四边形的高是垂直距离，不一定是斜边。
- **平均数**：不同人数的两组平均数不能直接取两个平均数的算术平均。
- **时间单位**：1小时=60分钟，不能按十进制换算。
- **面积/体积换算**：换算进率分别涉及平方、立方。
- **多步问题**：先求中间量，再用中间量求最终量，并在讲解中显示依赖关系。
- **信息不足**：缺少必要条件时不能自行补数值或假设。

## 5. 求解结果的数据契约

每道题的解题记录至少应包含：

- `problem_family`：题型 ID。
- `grade_band`：学段建议（可为空，不能仅凭题目武断判断年级）。
- `known_quantities`：量名、数值、单位、对象、原文依据。
- `target_quantity`：所求量及单位。
- `concepts`：知识点。
- `relation`：数量关系。
- `formula`：使用的公式。
- `formula_rearrangement`：公式变形。
- `calculation_steps`：逐步算式。
- `answer`：答案。
- `verification`：验证方法和验证结果。
- `verification_status`：verified / unverified。
- `assumptions`：使用的假设；默认必须为空，确有假设时明确展示。

## 6. 工程迭代建议

1. 先建设确定性公式规则：正方形、长方形、三角形、平行四边形、梯形、圆、单价数量总价、平均数、行程、百分数、单位换算。
2. 为每条规则建立正向题、逆向题、缺条件、单位冲突、数字顺序干扰等测试。
3. 对规则未覆盖的题目再调用 LLM，要求输出结构化条件与关系；独立校验失败时降级为未验证。
4. 以30–50道小学数学回归题作为第一批验收集，逐题核对题意、过程、单位、答案和视频旁白。
5. 不把知识点覆盖率等同于求解正确率；每条规则必须有可重复的测试证据。
