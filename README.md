# EduMotion AI

AI-powered teaching content generation for primary and secondary education.

## Scope

- Mathematics problem explanations and Chinese-language stories
- Shared Lesson IR for interactive web lessons and rendered videos
- Local-first development, with a path to cloud deployment

## Repository layout

- `backend/` — FastAPI application and asynchronous workers
- `frontend/` — Vue 3 + TypeScript application
- `shared/lesson-ir/` — JSON Schema and sample lesson documents
- `infra/` — local development infrastructure
- `scripts/` — developer utilities

## Quick start

See the backend and frontend READMEs for setup instructions. Copy `.env.example` to `.env` before starting local services.
